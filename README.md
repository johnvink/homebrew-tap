# Juleep Homebrew tap

```sh
brew install --cask juleep/tap/juleep
```

Installs the same notarised build published at https://github.com/johnvink/juleep-releases, and `brew upgrade` keeps it current. Juleep is private voice dictation for Mac: hold a key, speak, and the cleaned-up text is typed into any app, with speech recognition and cleanup running on the Mac. https://juleep.com

Apple Silicon, macOS 13 or later.
